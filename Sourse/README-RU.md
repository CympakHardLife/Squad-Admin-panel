# SquadAdmin — панель администрирования Squad-сервера

English version: README-EN.md

Одна программа `SquadAdmin.exe`. Установка не нужна, зависимостей нет.
Запускается на той же машине, где работает Squad-сервер, и открывает панель
в браузере по адресу `http://127.0.0.1:8080`.

---

## Быстрый старт

1. Скопируйте `SquadAdmin.exe` в отдельную папку — например `C:\SquadAdmin\`.
   **Не кладите его в папку Squad-сервера**: рядом с exe программа создаёт свои файлы.
2. Запустите двойным щелчком.
3. Windows покажет предупреждение SmartScreen «Система Windows защитила ваш компьютер»
   — это нормально для программ без платной цифровой подписи.
   Нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Откроется браузер с панелью. Если не открылся — зайдите вручную:
   `http://127.0.0.1:8080`
5. Вход по логину и паролю не нужен — панель открывается сразу.
   Она рассчитана на локальный запуск на вашей машине и слушает только
   `127.0.0.1`. Не открывайте её порт в интернет (см. раздел «Частые задачи»).

Окно консоли, которое появилось при запуске, **закрывать нельзя** — пока оно открыто,
панель работает. Чтобы остановить панель, закройте это окно или нажмите в нём `Ctrl+C`.

## Настройка

Откройте раздел **Настройки** в панели. Заполнять нужно две вещи.

### 1. RCON — без него не работает модерация

Возьмите данные из файла настроек вашего сервера
`<папка сервера>\SquadGame\ServerConfig\Rcon.cfg`:

```
Password=вашпароль      ← это пароль RCON
Port=21114              ← это порт RCON
```

В панели заполните:

| Поле | Значение |
|---|---|
| Адрес | `127.0.0.1` (панель и сервер на одной машине) |
| Порт | из `Rcon.cfg`, обычно `21114` |
| Пароль | из `Rcon.cfg` |

Нажмите **«Проверить подключение»** — должно появиться название вашего сервера.

> Если проверка не проходит: убедитесь, что сервер запущен, что в `Rcon.cfg` задан
> непустой пароль, и что сервер стартовал с параметром `RCONPORT=<порт>`.
> Squad не поднимает RCON, если пароль в `Rcon.cfg` пустой.

### 2. Папка сервера — для конфигов, логов и управления процессом

| Поле | Что указать | Пример |
|---|---|---|
| Папка сервера | Корень установки Squad-сервера | `C:\servers\squad` |
| Папка конфигов | Оставьте пустым — определится сама | `…\SquadGame\ServerConfig` |
| Файл лога | Оставьте пустым — определится сам | `…\SquadGame\Saved\Logs\SquadGame.log` |
| Файл запуска сервера | exe сервера, если хотите управлять запуском из панели | `C:\servers\squad\SquadGameServer.exe` |
| Аргументы запуска | Те же, что в вашем `.bat`-файле | `Port=7787 QueryPort=27165 RCONPORT=21114` |

Нажмите **«Проверить папку»** — панель отчитается, сколько конфигов нашла и виден ли лог.

Пока папка не указана, разделы **Конфиги** и **Логи** показывают заглушку.
Пока не указан файл запуска — раздел **Процесс** тоже недоступен. Всё остальное
(игроки, консоль, карты, баны, база игроков, автоматизация) работает на одном RCON.

## Что умеет панель

| Раздел | Возможности |
|---|---|
| **Обзор** | Состояние сервера, счётчик игроков, текущая и следующая карта, живая лента событий |
| **Игроки** | Дерево команд и отрядов, поиск, предупреждение, кик, бан, смена команды, роспуск отряда, снятие командира |
| **Консоль** | Любые RCON-команды с подсказками и историей |
| **Карты** | Список слоёв, смена текущего и следующего, завершение и рестарт матча |
| **Баны** | Локальная база банов со сроками, правкой, снятием и выгрузкой в формате `Bans.cfg` |
| **База игроков** | История ников, сессии, суммарный налёт, наказания, заметки администраторов |
| **Конфиги** | Правка любых `.cfg`, структурный редактор `Admins.cfg` (группы и права галочками), редактор ротации карт |
| **Логи** | Чат, тимкиллы, входы и выходы, ошибки; просмотр сырого лога |
| **Процесс** | Запуск, остановка и рестарт сервера, предупреждение игроков, автоперезапуск при падении |
| **Автоматизация** | Сообщения по интервалу и расписанию, команды и рестарты по расписанию, режим сидинга |
| **Журнал** | Всё, что делала панель: команды, баны, правки конфигов, срабатывания правил |

## Файлы рядом с exe

```
C:\SquadAdmin\
├── SquadAdmin.exe
├── config.json     — настройки (можно править вручную, когда панель закрыта)
└── data.db         — база: баны, игроки, заметки, правила, журнал
```

**Резервная копия** — просто скопируйте `config.json` и `data.db`.
Для переноса на другой компьютер скопируйте всю папку целиком.

Перед каждой записью в конфиг сервера панель делает резервную копию рядом с
исходным файлом: `Server.cfg.bak-20260802-194452`. Хранятся последние 10 копий.

## Частые задачи

**Открыть панель с другого компьютера в домашней сети.**
Настройки → Общие → включить «Слушать все интерфейсы», сохранить, перезапустить
`SquadAdmin.exe`. Заходить по `http://<IP-компьютера>:8080`.
Возможно, потребуется разрешить порт в брандмауэре Windows.
Наружу, в интернет, этот порт пробрасывать нельзя: в панели нет входа по
паролю, поэтому любой, кто достучится до порта, получит полный доступ.
Открывайте её только в доверенной локальной сети.

**Сменить порт панели.**
Настройки → Общие → «Порт панели». Применится после перезапуска программы.
Если панель не запускается из-за занятого порта, порт можно поправить прямо
в `config.json` (поле `general.panelPort`) в блокноте.

**Запускать панель вместе с Windows.**
Нажмите `Win+R`, введите `shell:startup`, скопируйте в открывшуюся папку ярлык
на `SquadAdmin.exe`.

**Автоперезапуск сервера при падении.**
Раздел Процесс → тумблер «Автоперезапуск при падении». Панель проверяет процесс
каждые 5 секунд и поднимает его заново. Если сервер падает больше 3 раз за
10 минут, автоперезапуск останавливается — значит, проблема не разовая
и её нужно смотреть в логах.

**Сидинг.**
Автоматизация → Добавить правило → «Сидинг». Укажите порог включения (например,
меньше 20 игроков), порог выключения (например, больше 50), слой для сидинга и
боевой слой. Панель сама переключит карту и будет напоминать игрокам о сидинге.
Пороги специально разные — так режим не будет дёргаться туда-сюда на границе.

## Если что-то не работает

**Панель не открывается в браузере.** Проверьте, что окно консоли `SquadAdmin.exe`
открыто и в нём нет строки «ОШИБКА». Откройте `http://127.0.0.1:8080` вручную.

**Красная плашка «RCON не подключён».** Сервер выключен, либо неверны порт или пароль,
либо сервер запущен без `RCONPORT`. Проверьте кнопкой «Проверить подключение».

**В разделе Логи пусто.** Squad пишет лог только когда сервер запущен. Панель читает
файл с момента своего старта и не разбирает то, что было записано раньше.

**Антивирус удалил exe.** Программы на Go без цифровой подписи иногда попадают под
эвристику. Добавьте папку `C:\SquadAdmin\` в исключения антивируса.

**Игрока не удаётся забанить.** Если игрок не в сети, бан сохранится в базе панели,
но на сервер не уйдёт. Выгрузите баны кнопкой «Экспорт Bans.cfg» в разделе Баны и
положите файл в `SquadGame\ServerConfig\`.

## Технические детали

- Один исполняемый файл, внутри — веб-интерфейс. Интернет не требуется:
  ни шрифты, ни библиотеки извне не загружаются.
- Хранилище — SQLite в файле `data.db`.
- Входа по логину/паролю нет: панель рассчитана на локальный запуск и слушает
  `127.0.0.1`. Запросы принимаются только с этого же компьютера — проверяются
  заголовки `Host`, `Origin` и `Sec-Fetch-Site`, всё остальное получает 403.
  Разграничение доступа — на уровне ОС и сети.
- Опрос сервера по RCON — раз в 20 секунд (настраивается), обновления в интерфейс
  приходят потоком, страницу перезагружать не нужно.

## Что нового в 1.0.1

- **Убран вход по логину и паролю.** Панель открывается сразу — она рассчитана
  на локальный запуск автором хостинга. Экран входа, смена пароля и хранение

- **Исправлено падение всей панели при аномальном RCON-пакете.** Раньше пакет с
  некорректно заявленным размером мог уронить процесс; теперь такой поток просто
  переподключается.
- **Исключён двойной запуск сервера.** Ручной «Старт» и автоперезапуск при
  падении больше не могут стартовать два процесса одновременно.
- **Честная остановка сервера.** Кнопка «Остановить» больше не рапортует об
  успехе, если процесс на самом деле продолжает работать.

## Что нового в 1.0.2

Закрыты важные замечания технического аудита (критичные были устранены в 1.0.1).

- **Панель отвечает только на этом компьютере.** Проверяются заголовки `Host`,
  `Origin` и `Sec-Fetch-Site`; обращения с других машин и со сторонних сайтов
  получают 403. Это закрывает DNS-rebinding и CSRF — актуально, раз входа по
  паролю больше нет. При `bindAll` сокет по-прежнему слушает сеть, но пускает
  только локальные запросы.
- **Конфиги пишутся атомарно.** Сохранение `Admins.cfg`, `Bans.cfg`, `Server.cfg`
  идёт через временный файл с последующей заменой. Обрыв записи (сбой, антивирус,
  отключение питания) больше не оставит обрезанный конфиг.
- **Комментарии в `Admins.cfg` сохраняются.** Отдельные строки-комментарии между
  группами и админами больше не превращаются в пустые строки при сохранении
  через структурный редактор.
- **Правило автоматизации не сработает дважды.** Добавлена настоящая защита от
  повторного входа. Если состояние правила не удалось сохранить, рестарт по
  расписанию отменяется и пишется ошибка — вместо риска второго рестарта.
- **Ротация лога определяется по содержимому файла.** Пересозданный
  `SquadGame.log` распознаётся, даже если успел дорасти до прежней позиции
  между проверками; события первых секунд после рестарта больше не теряются.
  Заодно пропускается UTF-8 BOM в начале файла.
- **Список игроков терпим к нестандартным строкам.** Боты/AI и изменённый после
  патча Squad формат больше не выпадают молча: строка разбирается по более
  мягкому шаблону, а нераспознанное пишется в журнал.
- **База данных готова к обновлениям.** Введено версионирование схемы, поэтому
  будущие изменения структуры применятся к уже существующему `data.db`,
  а не приведут к ошибке «no such column».
- **Данные в интерфейсе не «мигают».** Опрос RCON больше не запускается
  параллельно сам с собой после бана или кика.
- **Задержка RCON показывается честно.** Раньше выводилось «время опроса / 5»,
  теперь — реальный round-trip одной команды.

## Что нового в 1.0.3

Устранены оставшиеся мелочи технического аудита.

- **Корректный `Cache-Control` для статики.** Заголовок изменён с `no-cache` на
  `no-store` — ответ теперь не хранится ни в каком кэше.
- **Поиск работает как ожидается.** Спецсимволы `%` и `_` в строке поиска больше
  не совпадают с произвольным текстом: они экранируются перед LIKE-запросом.
- **Валидация правила сидинга.** При `switchLayer: true` поля `seedLayer` и
  `liveLayer` обязательны — ошибка возвращается при создании правила, а не при
  его срабатывании.
- **Конфиги сохраняются с CRLF.** При «сыром» редактировании `.cfg` переводы строк
  нормализуются в `\r\n` — Squad на Windows требует именно их.
- **Транзакции в ключевых операциях базы игроков.** `UpsertSeenPlayer`,
  `SessionStart`, `SessionEnd` теперь атомарны; счётчики сессий и плейтайма
  обновляются вместе со своими основными записями.
- **Убраны мёртвые параметры из `doStopWindows`.** `cmd` и `cmdDead` — POSIX-
  объекты, неприменимые на Windows; сигнатура функции упрощена.
- **Документирован паттерн «сломанного» пакета Squad.** Комментарий теперь содержит
  точную байтовую сигнатуру и подсказку, что проверять при будущих патчах игры.

## Что нового в 1.0.4

Косметическое обновление: панель переоформлена в тематике Squad. Логика,

  вместе с кириллицей: интернет по-прежнему не нужен.
- **Консоль в стиле полевого терминала.** Тёмное поле с фосфорным текстом,
  команды выделены янтарным.
- **Меню разбито на группы** — «Оперативно», «Модерация», «Сервер», «Система»;
  вместо символов — векторные иконки, которые не зависят от системных шрифтов.
- **Часы в верхней панели** и метка версии в подвале меню.
- **Мелкие правки удобства.** Поля поиска и выпадающие списки в панелях
  инструментов больше не растягиваются на всю ширину; подписи чекбоксов
  читаются обычным регистром; ссылки-кнопки («Экспорт Bans.cfg») больше не
  подчёркиваются.

Что осталось прежним: адреса, настройки, формат `config.json` и `data.db`,
все разделы и горячие пути. Обновление сводится к замене `SquadAdmin.exe`.

## Что нового в 1.0.5

- **Смена фона рабочей области.** В «Настройки → Оформление» — десять встроенных
  тематических фонов: полевая позиция (стандарт), командный пункт, штабная карта,

- **Режим «день / ночь».** Кнопка с солнцем/луной в верхней панели мгновенно
  переключает панель между дневной и ночной темой; та же настройка есть в
  «Настройки → Оформление». Ночная тема — тёмный штаб при дежурном свете:
  тёмная рабочая область, приглушённые линии, читаемые статусы.
- **Выбор запоминается.** Тема и фон сохраняются в браузере и применяются до
  первой отрисовки — панель не «мигает» светлой темой при загрузке.
- **Проверка файлов перед записью.** Всё, что добавляется и изменяется через
  панель, теперь проверяется в зависимости от типа и расширения файла:
  - редактировать можно только `*.cfg` (exe, dll, bat и прочее панель
    отклоняет);
  - бинарные данные, не-UTF-8 и файлы больше 1 МБ не записываются;
  - `Admins.cfg` — построчная проверка `Group=…`/`Admin=…`, идентификаторов
    SteamID64/EOS и токенов прав;
  - файлы ротации и списков исключений — проверка имён слоёв;
  - `Bans.cfg` — формат `ID:срок` с необязательным комментарием;
  - `Server.cfg` и `Rcon.cfg` — формат `Параметр=значение`;
  - `RemoteAdminListHosts.cfg` / `RemoteBanListHosts.cfg` — только адреса
    `http(s)://`;
  - свободные тексты (`MOTD.cfg`, `ServerMessages.cfg` и др.) — без жёстких
    ограничений формата.
  Ошибка возвращается с номером строки и понятным объяснением; файл на диске
  при этом не трогается (запись по-прежнему атомарная, с бэкапом).
- **Проверка путей в настройках сервера.** «Путь к exe» принимает только
  `.exe`, «Лог-файл» — `.log`/`.txt`, пути должны быть полными и без `..`.

Формат `config.json`, `data.db` и API не менялись. Обновление сводится к
замене `SquadAdmin.exe`.

### Смена языка интерфейса

В панель добавлен переключатель языка — русский / английский.

все разделы интерфейса, названия фоновых пресетов, подсказки команд в консоли,
единицы времени, сообщения об ошибках, а также сообщения бэкенда — записи

уведомления и события игрового лога (входы, выходы, тимкиллы).

**Что остаётся на русском:**
только произвольный пользовательский текст, введённый по-русски (причины банов,
заметки, тексты сообщений игрокам), и незнакомые панели строки — они показываются
как есть.

**Выбор сохраняется в браузере** (localStorage, ключ `sa_lang`, по умолчанию
русский) — так же, как тема и фон. На каждом браузере и компьютере настройка
выбирается независимо.

Формат `config.json`, `data.db` и API не менялись. Обновление сводится к
замене `SquadAdmin.exe`.
